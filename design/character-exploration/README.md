# Mochi character exploration

Six independent, unedited original PNG files generated with the built-in image_gen.imagegen tool. Runtime model identifier was not exposed. Constraints were delivered inside each main prompt. All images are 1254 × 1254 pixels. A1 was selected by the user and promoted to app icons and in-app mascot surfaces.
